# 🎾 Календарь Большого шлема

Автоматический календарь турниров Большого шлема с разделением на основные матчи (четвертьфиналы и дальше) и второстепенные (ранние раунды).

## Возможности

- **Автоматическое обновление** — расписание обновляется через GitHub Actions без ручного вмешательства
- **Два календаря** — отдельно для ключевых матчей (1/4 финала, полуфиналы, финалы) и ранних раундов
- **До матча** — показывает соперников, время, корт и обратный отсчёт
- **Во время матча** — индикатор LIVE и текущий счёт по сетам
- **После матча** — итоговый счёт и победитель
- **Фильтры** — по статусу (предстоящие/live/завершённые) и категории (ATP/WTA)
- **Адаптивный дизайн** — работает на телефоне и компьютере

## Что вам понадобится

1. **Аккаунт GitHub** (бесплатный) — зарегистрируйтесь на [github.com](https://github.com)
2. **API ключ Sportradar** (бесплатный) — для получения данных о матчах

## Пошаговая инструкция

### Шаг 1. Регистрация на GitHub

1. Откройте [github.com](https://github.com)
2. Нажмите **Sign up** в правом верхнем углу
3. Введите email, придумайте пароль и имя пользователя
4. Подтвердите email (вам придёт письмо со ссылкой)
5. Выберите бесплатный план (Free)

### Шаг 2. Создание репозитория

1. После входа на GitHub нажмите зелёную кнопку **New** (или плюсик в правом верхнем углу → New repository)
2. Заполните форму:
   - **Repository name**: `grand-slam-calendar`
   - **Description**: `Автоматический календарь турниров Большого шлема`
   - Выберите **Public** (чтобы сайт был доступен всем)
   - Поставьте галочку **Add a README file**
3. Нажмите **Create repository**

### Шаг 3. Загрузка файлов проекта

#### Вариант А: Загрузка через веб-интерфейс (проще для новичков)

1. В вашем репозитории нажмите кнопку **Add file** → **Upload files**
2. Перетащите все файлы и папки из этого проекта в окно загрузки
3. Обязательно сохраните структуру папок:
   ```
   grand-slam-calendar/
   ├── index.html
   ├── styles.css
   ├── app.js
   ├── data/
   │   └── matches.json
   ├── scripts/
   │   └── fetch_tennis.py
   └── .github/
       └── workflows/
           └── update-schedule.yml
   ```
4. Внизу страницы в поле **Commit changes** напишите: "Загрузка файлов проекта"
5. Нажмите **Commit changes**

> Важно: папки `.github/workflows/` нужно создавать вручную. Сначала создайте файл `.github/workflows/update-schedule.yml` через интерфейс GitHub (Add file → Create new file), введите путь с слэшами, и GitHub сам создаст папки.

#### Вариант Б: Через командную строку (если установлен Git)

```bash
# Клонируем репозиторий
git clone https://github.com/ВАШ_НИК/grand-slam-calendar.git
cd grand-slam-calendar

# Копируем все файлы проекта в эту папку

# Отправляем изменения
git add .
git commit -m "Загрузка файлов проекта"
git push
```

### Шаг 4. Получение бесплатного API ключа Sportradar

1. Откройте [developer.sportradar.com](https://developer.sportradar.com/)
2. Нажмите **Sign Up** и создайте аккаунт (бесплатно)
3. После входа перейдите в раздел **API Keys** (или **My Apps**)
4. Создайте новое приложение:
   - Name: `Grand Slam Calendar`
   - Выберите продукт: **Tennis v3** (Trial)
5. Скопируйте ваш API ключ (длинная строка символов)

> Бесплатный план (Trial) позволяет делать до 1000 запросов в месяц. При 4 запусках в день и ~18 запросах за запуск это ~720 запросов/месяц — в пределах лимита. Если лимит исчерпан, обновления приостановятся до начала следующего месяца.

### Шаг 5. Добавление API ключа в GitHub Secrets

1. В вашем репозитории на GitHub перейдите во вкладку **Settings** (наверху)
2. В левом меню найдите раздел **Secrets and variables** → **Actions**
3. Нажмите зелёную кнопку **New repository secret**
4. Заполните:
   - **Name**: `SPORTRADAR_API_KEY` (точно так, заглавными буквами)
   - **Secret**: вставьте ваш скопированный API ключ
5. Нажмите **Add secret**

> API ключ хранится в зашифрованном виде и не виден другим людям. Это безопасный способ хранения секретных данных.

### Шаг 6. Включение GitHub Pages

1. В репозитории перейдите во вкладку **Settings**
2. В левом меню найдите **Pages**
3. В разделе **Build and deployment**:
   - **Source**: выберите **Deploy from a branch**
   - **Branch**: выберите `main` и папку `/ (root)`
4. Нажмите **Save**
5. Через 1-2 минуты наверху появится ссылка на ваш сайт вида:
   ```
   https://ВАШ_НИК.github.io/grand-slam-calendar/
   ```

### Шаг 7. Включение GitHub Actions

1. В репозитории перейдите во вкладку **Actions**
2. Если появится сообщение о включении Actions — нажмите **I understand my workflows, go ahead and enable them**
3. В левом меню найдите workflow **"Обновление расписания Большого шлема"**
4. Нажмите **Enable Actions**

### Шаг 8. Первый запуск обновления

1. Во вкладке **Actions** выберите ваш workflow
2. Нажмите кнопку **Run workflow** (справа)
3. Нажмите зелёную кнопку **Run workflow**
4. Дождитесь завершения (1-2 минуты) — должен появиться зелёный кружок
5. Откройте ваш сайт GitHub Pages — данные обновятся автоматически

## Как это работает

```
┌─────────────────────────────────────────────────────┐
│                    GitHub Actions                    │
│         (запускается каждые 30 минут)                │
│                                                     │
│  fetch_tennis.py → Sportradar API → matches.json    │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                   GitHub Pages                        │
│                                                     │
│  index.html + app.js → читает matches.json →        │
│  показывает календарь с матчами                      │
└─────────────────────────────────────────────────────┘
```

1. **GitHub Actions** запускается автоматически каждые 30 минут
2. Скрипт `fetch_tennis.py` обращается к Sportradar Tennis API
3. Получает расписание матчей Большого шлема на ближайшие дни
4. Разделяет матчи на основные (1/4+) и второстепенные
5. Сохраняет данные в `data/matches.json`
6. GitHub Pages автоматически обновляет сайт

## Демонстрационные данные

В файле `data/sample_matches.json` находятся демонстрационные матчи для просмотра сайта без подключения API. Чтобы использовать их, переименуйте файл в `data/matches.json`.

В обычном режиме файл `data/matches.json` пустой и заполняется автоматически скриптом при первом запуске.

## Частота обновления

- **4 раза в день** (каждые 6 часов) — достаточно для актуального расписания
- При необходимости можно увеличить частоту в `.github/workflows/update-schedule.yml` (измените cron)
- Каждый запуск делает ~18 запросов к API (проверка 18 дней), что при 4 запусках/день даёт ~720 запросов/месяц

## Решение проблем

### Сайт не обновляется

1. Проверьте вкладку **Actions** — есть ли ошибки в последних запусках
2. Убедитесь, что API ключ добавлен правильно (Settings → Secrets → Actions)
3. Запустите workflow вручную (Run workflow)

### Ошибка 403 или 429 от API

- Превышен лимит запросов бесплатного плана
- Уменьшите частоту обновления в `.github/workflows/update-schedule.yml` (измените cron)
- Например, для обновления раз в час: `0 * * * *`

### Страница GitHub Pages не открывается

1. Проверьте Settings → Pages — включена ли публикация
2. Убедитесь, что файл `index.html` находится в корне репозитория
3. Подождите 5-10 минут после первого включения

### Нет матчей на сайте

- Это нормально вне турнирных периодов
- Матчи появятся автоматически за несколько дней до начала турнира
- Вы можете проверить, работает ли API, запустив скрипт локально:
  ```bash
  export SPORTRADAR_API_KEY=ваш_ключ
  python scripts/fetch_tennis.py
  ```
